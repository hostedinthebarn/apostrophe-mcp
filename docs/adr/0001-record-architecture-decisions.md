# 1. Record architecture decisions

- **Status:** accepted
- **Date:** 2026-11-16

## Context

Some choices in this project will be hard to reverse, surprising without context, or a real trade-off. Without a record, the reason is lost and the choice gets argued again.

## Decision

Record each such choice as a numbered file in `docs/adr/`: context, decision, consequences. A superseded ADR stays, marked "superseded by N".

## Consequences

Small decisions don't need one. If a reviewer would ask "why on earth…?", write an ADR.
