# apostrophe-mcp

An open-source [Model Context Protocol](https://modelcontextprotocol.io) server for [ApostropheCMS 4](https://apostrophecms.com), so the people who look after an Apostrophe site can update it by asking Claude. Built by Hosted in the Barn.

**Status:** not started. The design is being settled; the first site to use it is [church-system](https://github.com/hostedinthebarn/church-system).

The plan: a remote server that each editor signs into as their own Apostrophe user, so the site's history shows who changed what. Content changes are saved as drafts for a person to publish.

MIT licensed. Changes reach `main` through pull requests only.
